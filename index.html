Dashboard Rate Rujukan FKTP
Pemantauan capaian rujukan dibandingkan target bulanan per fasilitas kesehatan. Capaian rujukan Oktober sampai pembaruan terakhir yang melebihi target diberi tanda merah sebagai indikator perlunya evaluasi.
Menghubungkan Google Sheets. Data awal belum terverifikasi sebagai data terbaru.
Aturan status: Jika capaian rujukan Oktober sampai pembaruan terakhir lebih besar daripada target rujukan bulanan, status berwarna MERAH — Belum optimal, perlu evaluasi. Jika capaian sama dengan atau di bawah target, status hijau — dalam target. Status ini merupakan indikator pemantauan sesuai arahan pengguna, bukan penilaian menyeluruh terhadap mutu klinis. Status menggunakan tanggal data pada kolom capaian Oktober, bukan tanggal hari ini. Target pembanding adalah target satu bulan penuh, tanpa prorata harian. Status hijau belum merupakan hasil akhir bulan.
